## 📖 About GLX Tab Zoom Manager

### GLX Tab Zoom Manager: an individual zoom level for every website

GLX Tab Zoom Manager remembers the perfect zoom level for the websites you visit and applies it again automatically on your next visit. Perfect for high-resolution monitors, accessibility or complex web applications.

What makes it special: you not only set the zoom of every website, you can also organise your saved pages clearly, sort them into your own folders and keep important settings permanently.

### Smart storage down to the detail

Unlike conventional zoom extensions, this add-on remembers the zoom level per complete web address (including # anchors).

That is ideal for modern web applications such as ioBroker, smart home dashboards or web apps that control different views under the same domain via hash parameters (e.g. …/#tab-adapters and …/#tab-objects).

Every view gets exactly the zoom you want, independent of other pages of the same domain.

### 1. Automatic saving

Every change of the zoom level, whether via the add-on pop-up or the classic way with keyboard and mouse (Ctrl + mouse wheel), is detected and saved. Date and time of saving are recorded as well.

### 2. Live zoom pop-up with direct folder management

When the zoom changes, a pop-up appears with information on the current website and the zoom level set (e.g. 70 %).

Right in the pop-up you can:

- assign the saved page to an existing folder,
- create a new folder with the plus button,
- move the page into the selected folder immediately,
- apply changes to zoom levels that are already saved.

### 3. Convenient history and page management

The extended settings page gives you a complete overview of your saved websites. Even with 30, 40 or more saved pages you keep track.

- Search by page name or full web address.
- All saved websites with their zoom factor.
- Delete individual websites.
- Move saved pages to other folders afterwards.
- Edit zoom settings directly in the overview.
- See when each website was saved.

So you don't have to visit a website again to put it into another folder.

### 4. Your own folders for important websites

Organise your saved zoom settings just the way you like. Besides the built-in default folder General you can create as many folders as you want, for example:

- Smart Home
- ioBroker
- Nextcloud
- Administration
- Frequently used websites
- Personal favourites

The folder drop-down shows only the saved websites of the chosen folder. Every page can be moved or deleted individually.

Whole folders can be removed too; all websites and zoom settings stored in them are deleted as well. The default folder General always remains.

### 5. Smart automatic history cleanup

So that entries don't pile up over months, GLX Tab Zoom Manager offers an adjustable retention period:

- 1 week
- 2 weeks
- 3 weeks
- 4 weeks

The cleanup uses the saved dates and times.

Important: the automatic cleanup only affects the general storage area. Your own folders are protected and are never touched by the timed deletion.

So frequently visited websites are managed automatically while your permanently important pages stay.

### 6. Backup (import/export)

Back up all your zoom settings including folders and saved websites into one file with the export function. Ideal for backups, new installations or moving to another device. With the import function you restore your data at any time.

### 7. Modern design and individual settings

The add-on offers three designs:

- Light Theme: bright and clear.
- Dark Theme: a pleasant dark design.
- GLX Neon: futuristic design in the typical GLX neon look with glowing blue and turquoise accents.

The language can be set individually:

- German
- English
- Automatic, following the browser language.

### 8. Built-in help and settings

A detailed help page explains the features and how to use the add-on. The navigation takes you directly between settings and help at any time.

### Quick guide: this is how easy it is

- Click the extension icon in the Firefox toolbar.
- Set the zoom level with the + / − buttons; the page adapts immediately.
- GLX Tab Zoom Manager detects the change and informs you via the pop-up.
- If you like, assign the website to an existing or new folder right away.
- Your zoom setting is saved and applied again automatically on your next visit.

### Who is GLX Tab Zoom Manager for?

Developers, administrators, smart home users or regular internet users: anyone who regularly works with many different websites and prefers an individual view for each will appreciate this extension.

The separate storage is especially handy for complex web interfaces where different subpages of the same domain need different zoom levels.

## ✨ Features

- 🚀 **Zoom per address:** Saves an individual zoom level for every web address, including # sub-pages.
- 🧩 **Restores automatically:** The saved zoom is applied as soon as you open the address again.
- ⚙️ **Floating notice card:** When you change the zoom, a card in the page asks Save, Later or Never ask.
- 🔒 **Always readable:** The card keeps the same size no matter how far the page is zoomed.
- 📂 **Never ask:** Exclude a page for good and zoom it freely.
- ⚡ **Exclusion list:** All excluded addresses are listed in the settings, "Ask again" undoes it.
- 🎨 **Toolbar window:** Shows the state of the current page and lets you switch it back on.
- 🌍 **Works on special pages:** Where add-ons are not allowed in the page, the notice opens as a small window.
- 🛠️ **Access check:** If website access is missing, an "Allow access" button appears.
- 📊 **Three designs, two languages:** Light, dark and GLX Neon, German and English, built-in help.
